`@hitl-sh/cli` installs the `hitl` command. Use it from a terminal, a script, CI, or a coding agent with a shell. Node 20 or newer.

```bash
npx -y @hitl-sh/cli --help        # no install
npm i -g @hitl-sh/cli             # or install the hitl command
```

## Set up

<Steps>
<Step title="Log in with your key">
```bash
hitl login --api-key hitl_live_...      # saved in ~/.config/hitl/config.json (mode 0600)
# or: export HITL_API_KEY=hitl_live_...  (wins over the saved key)
hitl whoami
```

```text
jordan.lee@example.com (active)
key hitl_live_…fa7e from env
api https://api.hitl.sh/v1/
```
</Step>
<Step title="Find a workflow">
```bash
hitl workflows list
```

6af2ce5f8207961501f59482  Translation quality   active  3      true

```json

  "workflow_id": "6af2ce4e8207961501f59472",
  "fields": [
    { "path": "amount", "used_by": ["action-1", "review-1"] },

  },
  "note": "Fields the workflow's steps read as {{trigger.body.<path>}}. Other fields are accepted and passed through."

```
</Step>
<Step title="Run it and wait for the answer">
```bash
hitl run 6af2ce4e8207961501f59472 \
  --input '{"order_id":"ORD-48252","customer":{"name":"Mary Jackson","email":"mary@example.com"},"amount":320,"currency":"USD","reason":"Item never arrived."}' \
  --wait 600
```

Progress goes to stderr; the result goes to stdout once a person has answered:

```text
hitl: run 6af2d10bc6a9f1dc71efd5eb started
hitl: completed
6af2d10bc6a9f1dc71efd5eb completed
```

Add `--json` for the whole execution (`status`, `result`, `decisions`, ...), or use `--watch` for live updates instead of polling.
</Step>
</Steps>

### `hitl run`

```text
hitl run <workflow-id> [options]    (also: hitl workflows run)

Start a run of an active workflow.

  --input '{..}' or --data '{..}' or --file <path|->  What its steps read as {{trigger.body.<path>}}
  --callback-url <https url>  Receives the finished run
  --wait [seconds]            Wait for the run to finish (default 3600)
  --watch                     Like --wait, with live updates over Statewire
  --live                      Print the details for watching the run from elsewhere
  --json                      Print the whole run as JSON

Without --wait or --watch it prints the execution id. While waiting, it exits 0 if the run completed,
2 if it failed or timed out, and 5 if it had not finished when the wait ran out.
```

Use the exit code in scripts:

```bash
if hitl run "$DEPLOY_GATE" --input "{\"version\":\"$VERSION\"}" --wait 1800; then
  ./deploy.sh
else
  echo "Deploy not approved"; exit 1
fi
```

## Follow runs

```bash
hitl executions get <execution-id> --wait 30
hitl executions watch <execution-id>          # attach to a run in progress
hitl workflows runs <workflow-id> --status pending_review
hitl executions retry <workflow-id> <execution-id>
```

## Sign up without a browser

```bash
hitl signup --email ada@example.com --agent-name "Claude Code"   # saves the key
hitl signup confirm 123456                                        # the code from the email
hitl signup status
hitl signup resend
```

Until confirmed, the key can read and draft workflows; running them answers `confirmation_required`.

## Build a workflow

```bash
hitl workflows create --file refund.json          # a draft; see Workflows → Building without the editor
hitl workflows invite <id> --emails ada@example.com
hitl workflows join-code create <id>
hitl workflows activate <id>                      # a refusal says what to fix
hitl workflows test <id> --input '{"amount":49}'
hitl workflows pause <id>
```

`--help` on any area (`hitl workflows --help`) or command lists its options. Commands with a body take `--data '{..}'` or `--file <path|->`; flags override the JSON.

## Connect an MCP client

```bash
hitl init claude-code       # claude mcp add hitl -e HITL_API_KEY=… -- npx -y @hitl-sh/mcp
hitl init claude-desktop    # edits claude_desktop_config.json (backup kept as .bak)
hitl init cursor            # edits ~/.cursor/mcp.json (backup kept as .bak)
hitl init                   # prints the JSON for any other client
hitl mcp                    # run the MCP server over stdio
```

See [MCP server](/integrations/mcp).

## Reference

| | |
|---|---|
| `HITL_API_KEY` | Wins over the saved key |
| `HITL_API_BASE` | Default `https://api.hitl.sh/v1` |
| Exit codes | 0 ok, 1 usage, 2 failed, 3 no or rejected API key, 5 a followed run had not finished |
| `--json` | Machine-readable output on any command |
