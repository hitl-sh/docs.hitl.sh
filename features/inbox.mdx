# Inbox

The Inbox is where you review and respond to pending requests from all your loops. It provides a real-time view of everything waiting for your attention.

## Overview

When you navigate to **Inbox** in the sidebar, you'll see:

- **Pending requests** sorted by most recent, grouped by loop
- **Real-time badge** in the sidebar showing the count of pending requests (updates live)
- **Request details** with the full request text, media, and response interface
- **Your Loops** listed on the right for quick navigation

## Responding to Requests

Click any pending request to open its detail panel. Depending on the response type configured for the request, you'll see one of:

- **Text** — Free-form text input
- **Single Select** — Choose one option from a list
- **Multi Select** — Choose multiple options
- **Boolean** — Yes/No toggle
- **Rating** — Star or numeric rating
- **Number** — Numeric input
- **Editable Text** — Pre-filled text you can modify

After reviewing the request content, submit your response. The request moves from pending to completed and the result is sent back to the originating system via the API or webhook.

## Real-Time Updates

The Inbox updates in real time:

- New requests appear automatically without refreshing
- The red badge in the sidebar reflects the current pending count
- Completed requests disappear from the pending view

## Request Details

Each request card shows:

- **Loop name** and icon
- **Request text** (supports markdown)
- **Media attachments** — Images, documents, audio, or video if included
- **Priority level**
- **Time received**
- **Response type** expected

## Mobile

The Inbox is fully responsive. On mobile devices, you'll see the request list first, then tap into individual requests to respond. The mobile app also supports push notifications for new requests.
