# Inbox

The Inbox is where you review and respond to pending response requests from all your workflows. It provides a real-time view of everything waiting for your attention.

## Overview

When you navigate to **Inbox** in the sidebar, you'll see:

- **Pending responses** sorted by most recent, grouped by workflow
- **Real-time badge** in the sidebar showing the count of pending responses (updates live)
- **Response details** with the full request content, media, and response interface
- **Your Workflows** listed on the right for quick navigation

## Responding to Requests

Click any pending response to open its detail panel. Depending on the response type configured in the workflow's human review node, you'll see one of:

- **Text** -- Free-form text input
- **Single Select** -- Choose one option from a list
- **Multi Select** -- Choose multiple options
- **Boolean** -- Yes/No toggle
- **Rating** -- Star or numeric rating
- **Number** -- Numeric input
- **Editable Text** -- Pre-filled text you can modify

After reviewing the content, submit your response. The item moves from pending to completed, the workflow execution continues, and the result is available in the Executions tab.

## Real-Time Updates

The Inbox updates in real time:

- New response requests appear automatically without refreshing
- The red badge in the sidebar reflects the current pending count
- Completed items disappear from the pending view

## Response Details

Each response card shows:

- **Workflow name** and icon
- **Request content** (supports markdown)
- **Media attachments** -- Images, documents, audio, or video if included
- **Priority level**
- **Time received**
- **Response type** expected

## Mobile

The Inbox is fully responsive. On mobile devices, you'll see the response list first, then tap into individual items to respond. The mobile app also supports push notifications for new response requests.
