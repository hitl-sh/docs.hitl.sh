# Dashboard

The HITL dashboard gives you an at-a-glance view of your loops, usage, and activity. It's the first thing you see after logging in at [my.hitl.sh](https://my.hitl.sh).

## Connect Your Automation

At the top of the dashboard, you'll see integration buttons for connecting your preferred automation tools:

- **n8n** — Workflow automation
- **Zapier** — App integrations
- **Make** — Visual automation
- **MCP** — Model Context Protocol

Clicking any integration opens a setup guide with step-by-step instructions, API credentials, and configuration details — all without leaving the dashboard.

## Analytics

The dashboard displays four key metric cards:

| Metric | Description |
|--------|-------------|
| **Teams** | Number of active teams in your organization |
| **API Usage** | Requests used out of your plan limit, with a progress bar |
| **Active Loops** | Currently active human-in-the-loop workflows |
| **Total Members** | People across all your loops |

### Charts

Below the metric cards, you'll find:

- **Request Volume** — A 14-day area chart showing daily request trends
- **Request Status** — A donut chart breaking down pending, completed, and expired requests
- **Sources** — A breakdown of where requests originate (API, n8n, Zapier, Make, web portal, MCP)

## API Usage

The API Usage card shows your current consumption against your plan limit. The progress bar indicates how much of your request bucket you've used.

When your requests run out, you're automatically charged for a fresh bucket at your plan's rate. See [Billing](/billing) for details on plans and pricing.

<Info>
If you have a pending plan downgrade, the usage bar turns amber and shows which plan you'll switch to on your next auto-charge.
</Info>

## Navigation

The sidebar provides quick access to all sections:

- **Dashboard** — Overview and analytics
- **Loops** — Create and manage workflows
- **Inbox** — Review pending requests
- **API Keys** — Manage your API credentials
- **Enterprise** — Organization management (paid plans)
- **Billing** — Usage and plan management
- **Settings** — Profile, preferences, and linked devices
