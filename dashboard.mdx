# Dashboard

The HITL dashboard gives you an at-a-glance view of your workflows, usage, and activity. It's the first thing you see after logging in at [my.hitl.sh](https://my.hitl.sh).

## Connect Your Automation

At the top of the dashboard, you'll see integration buttons for connecting your preferred automation tools:

- **n8n** — Workflow automation
- **Zapier** — App integrations
- **Make** — Visual automation
- **MCP** — Model Context Protocol

Clicking any integration opens a setup guide with step-by-step instructions, API credentials, and configuration details — all without leaving the dashboard.

## Analytics

The dashboard displays four key metric cards:

| Metric | Description |
|--------|-------------|
| **API Usage** | Responses used out of your plan limit, with a progress bar |
| **Active Workflows** | Currently active human-in-the-loop workflows |
| **Total Members** | People across all your workflows |

### Charts

Below the metric cards, you'll find:

- **Response Volume** — A 14-day area chart showing daily response trends
- **Response Status** — A donut chart breaking down pending, completed, and expired responses
- **Sources** — A breakdown of where responses originate (API, n8n, Zapier, Make, web portal, MCP)

## API Usage

The API Usage card shows your current consumption against your plan limit. The progress bar indicates how much of your monthly allowance you've used.

Free plans include 500 responses per month. Enterprise plans include unlimited responses. See [Billing](/billing) for details on plans and pricing.

## Navigation

The sidebar provides quick access to all sections:

- **Dashboard** — Overview and analytics
- **Workflows** — Create and manage workflows
- **Inbox** — Review pending responses
- **API Keys** — Manage your API credentials
- **Enterprise** — Organization management (Enterprise plan)
- **Billing** — Usage and plan management
- **Settings** — Profile, preferences, and linked devices
