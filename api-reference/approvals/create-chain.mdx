# Create Approval Chain

Attach an approval chain to an existing request. The chain defines the approval steps, designated approvers, and evaluation mode.

<Note>
Only one approval chain can exist per request. Attempting to create a second chain returns a `409 Conflict` error.
</Note>

## Path Parameters

<ParamField path="requestId" type="string" required>
The ID of the request to attach the approval chain to
</ParamField>

## Request Body

<ParamField body="org_id" type="string" required>
The organization ID this approval chain belongs to
</ParamField>

<ParamField body="mode" type="string" required>
The evaluation mode for the chain. Must be `"sequential"` or `"parallel"`.
- **sequential**: Steps are evaluated in order — step N+1 only activates after step N is approved
- **parallel**: All steps are active simultaneously
</ParamField>

<ParamField body="steps" type="array" required>
Array of approval steps. At least one step is required.
<Expandable title="Step Object">
<ParamField body="step_order" type="integer" required>
Position of this step in the chain (starting from 1)
</ParamField>

<ParamField body="approver_ids" type="array" required>
Array of user IDs authorized to approve this step. At least one approver required.
</ParamField>

<ParamField body="require_all" type="boolean" optional default="false">
When `true`, all approvers must approve. When `false`, any single approval is sufficient.
</ParamField>
</Expandable>
</ParamField>

## Response

<ResponseField name="error" type="boolean">
Whether the request failed
</ResponseField>

<ResponseField name="msg" type="string">
Human-readable status message
</ResponseField>

<ResponseField name="data" type="object">
<Expandable title="data">
<ResponseField name="approval_chain" type="object">
The created approval chain object with all steps initialized to `pending` status.
</ResponseField>
</Expandable>
</ResponseField>

### Error Responses

| Status | Error | Description |
|--------|-------|-------------|
| `400` | Invalid request body | Missing or malformed fields |
| `400` | Invalid request ID format | The `requestId` path parameter is not a valid ID |
| `400` | At least one approval step is required | The `steps` array is empty |
| `409` | Approval chain already exists for this request | A chain was already created for this request |
