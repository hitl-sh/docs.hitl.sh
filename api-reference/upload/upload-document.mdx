# Upload Document

Upload a document file to HITL.sh hosting. The returned URL, file type, and filename can be used when creating requests with `type: "file"`.

## Request

<ParamField body="file" type="file" required>
Document file to upload. Must be one of the supported formats.
</ParamField>

### Supported Formats

| Format | MIME Type |
|--------|-----------|
| PDF | `application/pdf` |
| DOC | `application/msword` |
| DOCX | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| XLS | `application/vnd.ms-excel` |
| XLSX | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| PPT | `application/vnd.ms-powerpoint` |
| PPTX | `application/vnd.openxmlformats-officedocument.presentationml.presentation` |
| CSV | `text/csv` |
| TXT | `text/plain` |

### Limits

- **Maximum file size:** 50 MB
- **Content-Type:** `multipart/form-data`

## Response

<ResponseField name="error" type="boolean">
Whether the request failed
</ResponseField>

<ResponseField name="data" type="object">
<Expandable title="data">
<ResponseField name="url" type="string">
The hosted URL for the uploaded document. Use this as `file_url` in your request.
</ResponseField>

<ResponseField name="file_type" type="string">
Detected MIME type of the uploaded file (e.g., `"application/pdf"`)
</ResponseField>

<ResponseField name="file_name" type="string">
Original filename of the uploaded file
</ResponseField>

<ResponseField name="size_bytes" type="integer">
Size of the uploaded file in bytes
</ResponseField>
</Expandable>
</ResponseField>

### Success Response

```json
{
  "error": false,
  "data": {
    "url": "https://cdn.hitl.sh/uploads/docs/xyz789.pdf",
    "file_type": "application/pdf",
    "file_name": "vendor-agreement-2026.pdf",
    "size_bytes": 204800
  }
}
```
