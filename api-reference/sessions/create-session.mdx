---
title: "Create Session"
api: "POST https://dev.api.hitl.sh/v1/api/sessions"
description: "Start a new agent coding session. If loop_id is omitted the server auto-creates a scoped loop."
---

Create a new session scoped to the authenticated API key's user. Sessions contain turns — the individual actions the agent wants human review on.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer API key.
</ParamField>

## Body

<ParamField body="agent_type" type="string" default="claude">
  `claude` or `codex`.
</ParamField>

<ParamField body="loop_id" type="string">
  Existing loop to route turns into. If omitted, the server auto-creates a loop named `"<agent_type> — <repo>"` owned by the API-key user.
</ParamField>

<ParamField body="context" type="object">
  Session context for reviewers.

  <Expandable title="context">
    <ParamField body="repo" type="string">Repository URL or path.</ParamField>
    <ParamField body="branch" type="string">Current branch.</ParamField>
    <ParamField body="commit" type="string">Short commit SHA.</ParamField>
    <ParamField body="task" type="string">What the agent is trying to do (free text).</ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="error" type="boolean" />
<ResponseField name="msg" type="string" />
<ResponseField name="data.session" type="object">
  The newly created session (`id`, `status=active`, `loop_id`, `context`, `turn_count=0`, timestamps).
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://dev.api.hitl.sh/v1/api/sessions \
  -H "Authorization: Bearer $HITL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_type": "claude",
    "context": {
      "repo": "git@github.com:acme/app.git",
      "branch": "preview",
      "commit": "a1b2c3d",
      "task": "Add session export endpoint"
    }
  }'
```
</RequestExample>
